# Beta Error Reporting

Para ajudar a equipe a diagnosticar falhas no beta com mais rapidez, envie o relato com:

- Horário aproximado do erro
- Tela ou rota em que o problema aconteceu
- Ação que você estava executando
- Navegador e versão, quando souber
- Dispositivo usado
- Print ou gravação curta, se possível
- Código de referência, quando a interface ou o suporte informar um

Exemplo de relato útil:

`24/07/2026 14:35 - Creator Dashboard - cliquei em solicitar saque - Chrome no Android - tela travou após enviar - referência: abc123def456`

O que não enviar:

- Senha
- Token
- Cookie
- Chave Pix
- Dados bancários completos
- Conteúdo privado de postagens ou mensagens

Se o erro envolver pagamento, publicação, upload ou login social, informe também:

- se era a primeira tentativa ou repetição
- se a internet oscilou
- se a página foi recarregada antes da falha
