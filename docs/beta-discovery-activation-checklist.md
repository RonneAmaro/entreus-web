# Beta Discovery Activation Checklist

## Descoberta

- [ ] O Hub abre sem erro.
- [ ] A busca abre a partir da navegação e do Hub.
- [ ] A busca explica que cobre perfis públicos por nome e `@username`.
- [ ] Resultados de perfis aparecem quando existem dados compatíveis.
- [ ] O estado sem resultado é compreensível e indica o próximo passo.
- [ ] Perfis públicos podem ser abertos.
- [ ] Conteúdo permitido dentro do perfil público pode ser aberto.

## Feed Vazio

- [ ] As ações do feed vazio possuem destino real.
- [ ] Não há botão sem saída.
- [ ] O usuário consegue voltar ao feed depois de explorar perfis.
- [ ] O fluxo funciona em mobile.

## Perfil Público

- [ ] A identificação do criador está clara.
- [ ] A bio aparece quando disponível.
- [ ] As publicações visíveis permanecem acessíveis.
- [ ] A ação de seguir aparece apenas quando o fluxo já existe.
- [ ] O estado sem conteúdo é compreensível.
- [ ] O estado de perfil inexistente continua seguro.
- [ ] Conteúdo protegido ou exclusivo continua respeitando as regras atuais.

## Busca

- [ ] Termo vazio mostra descoberta inicial compreensível.
- [ ] Termo válido retorna perfis compatíveis.
- [ ] Termo sem resultado mostra orientação clara.
- [ ] O carregamento é compreensível.
- [ ] O erro é comunicado sem expor dados internos.
- [ ] É possível limpar a busca.
- [ ] O fluxo funciona por teclado.
- [ ] O fluxo funciona em mobile.

## Privacidade

- [ ] Nenhuma informação privada aparece na descoberta.
- [ ] Conteúdo pago continua protegido.
- [ ] Conteúdo privado continua protegido.
- [ ] Usuário bloqueado ou indisponível continua respeitando a regra atual.
